# Fall Detection Using YOLO

## Project Overview

This project detects human falls using YOLO and OpenCV.
It aims to identify potential falls from a video stream or camera
and send alerts through a Telegram bot.

## Technologies Used

- Python
- YOLO (Ultralytics)
- OpenCV
- Telegram Bot API

## Features

- Human detection
- Fall detection
- Video and camera processing
- Telegram notifications

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the fall detection script:

```bash
python fall_detection_yolo.py
```

Configure your Telegram bot before using the notification feature.

## Models

The project uses YOLO model files for human detection.
